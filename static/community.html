Report bugs, contribute code

Every public repository in the awsum-lang organization has its own issue tracker for bug reports and feature requests. For the compiler itself, open an issue at github.com/awsum-lang/awsum/issues.

For code contributions, see CONTRIBUTING.md in any repository — development setup, signed-commit policy, and PR conventions.

Report security issues

Suspected security vulnerabilities go through a private channel — not through the public issue tracker. The preferred route is GitHub Private Vulnerability Reporting: github.com/awsum-lang/awsum/security/advisories/new. Fallback channel and full policy (scope, supported versions, response timeline) are in SECURITY.md.
