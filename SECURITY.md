# Security Policy

## Reporting a vulnerability

Report suspected security vulnerabilities in [awsum-lang.org](https://awsum-lang.org) through one of the following channels:

- **Preferred:** [GitHub Private Vulnerability Reporting](https://github.com/awsum-lang/awsum-lang.org/security/advisories/new) — visible only to maintainers and the reporter, and can be coordinated into a published advisory with a CVE.
- **Fallback:** email `security@awsum-lang.org` with subject `[security] <short description>`.

Please do not report security vulnerabilities through public issues, pull requests, or discussions.

## Scope

Issues on `awsum-lang.org` that allow stored XSS, redirect to malicious destinations, or content injection.

## Supported versions

The site is continuously deployed from `main`. Security fixes are applied to `main` and redeployed; there are no maintained branches.

## Response timeline

We aim to acknowledge new reports within 7 days and to publish a fix or mitigation within 90 days. Reporters will be kept informed throughout.
